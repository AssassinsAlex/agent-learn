## 架构亮点：Session Tree

在本学习范围内，Pi 的一个显著实现特征是：同一个 durable session 内部用 `parentId + leaf` 表达多分支历史，并从 active leaf 重新投影模型上下文。需要注意，仓库中有两套相似实现：coding-agent 的 `SessionManager`（CLI 实际使用）和 agent-core Harness 的通用 `Session`。DeepSeek Harness 更偏向 append-only `SessionEvent` log，Codex 更偏向 fork 出独立 thread/rollout；详细对比见[跨项目 Session 对比](跨项目Session对比.md)。

## 分层架构

```text
pi-coding-agent (CLI / modes / coding tools / session orchestration)
              |
              v

              |
              v
      Anthropic / OpenAI / Google / Bedrock / ...

pi-coding-agent ----> pi-tui (interactive terminal rendering)
pi-coding-agent ----> storage packages (optional persistence)
```

## Agent 主闭环

```text
用户输入 / 命令
        |
        v
`main.ts` / mode ---> `AgentSession` 状态 ---> context/model request
        |                              |
        v                              v
interactive/TUI <--- `AgentSessionEvent` <--- `AgentEvent` <--- `pi-ai` stream
        ^                              |
        |                              v
        +----- tool result <--- `executeToolCalls` <--- assistant tool calls
```

`agentLoop()` 先把 prompt 放入 `AgentContext`，发出 `agent_start`/`turn_start`，通过 `streamAssistantResponse()` 获取 assistant 流；如果出现 tool calls，则按配置串行或并行执行，写入 `ToolResultMessage`，再次请求模型。每个 turn 发出 `turn_end`；最终发出 `agent_end`。源码还显式处理 steering messages、follow-up messages、截断 tool arguments、abort/error 和 `prepareNextTurn`。

## 术语表

| 术语 | 本学习档案中的含义 |
| --- | --- |
| Agent loop | 驱动模型调用与工具调用直到停止的一轮或多轮控制循环 |
| Turn | 用户一次输入引起的一段连续处理过程 |
| Context | 被发送给模型的消息、指令、工具定义及相关元数据 |
| Tool result | 工具执行后作为消息回填给模型的结构化或文本结果 |
| Provider | 屏蔽不同模型服务 API 差异的适配层 |

## Session 树补充映射

```text
SessionStorage / JSONL
  -> Session.getBranch()
  -> Session.buildContext()
  -> AgentContext
  -> Agent loop
  -> AgentEvent.message_end
  -> Session.appendMessage()
  -> new leaf
```

当 context 接近模型窗口上限时，Harness 在这条链路旁执行：

```text
active branch -> estimate/shouldCompact -> prepareCompaction -> compact
  -> appendCompaction -> 下一次 buildContext 投影为 summary + retained tail
```

详细说明见：[树状 Session 详解](../01-核心模块/04-树状Session详解.md) 和 [Compaction 层详解](../01-核心模块/09-Compaction层详解.md)。
