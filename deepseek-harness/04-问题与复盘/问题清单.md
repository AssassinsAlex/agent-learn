## 复盘方向

DeepSeek Harness 最值得和 Pi 对比的不是“是否有 compaction”，而是：

```text
Pi 的 session tree / branch projection
vs
DeepSeek Harness 的 append-only SessionEvent + surface replacement
```

下一轮应使用相同的输入、tool result 和 overflow 条件，对比两者的日志可恢复性、KV cache 影响、并发稳定性和失败后的重试语义。
