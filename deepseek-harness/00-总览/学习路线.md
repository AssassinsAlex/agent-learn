# 学习路线

## 总体顺序

```text
项目与启动配置
  -> Cordis / profile / bundle
    -> Agent、inbox、turn/step
      -> Session Log 与 surface projection
        -> system prompt、tools、LLM request
          -> token-meter
            -> compaction / tool-result pruning
              -> Web/API/RPC 与可观测性
```

## 建议阶段

1. 读 `README`、`docs/architecture.md` 和 `pnpm-workspace.yaml`，建立包地图。
2. 读 `apps/cli`、`packages/boot`、`packages/bundle`，理解启动时如何生成 Cordis plugin tree。
3. 读 `packages/core/agent` 和 `packages/core/agent-loop`，掌握 inbox、turn、step、工具循环和取消。
4. 读 `packages/core/session`，理解 append-only events、surface、deriveMessages、resume 和 fork。
5. 读 `packages/core/system-prompt`、`packages/core/tools`，理解 prompt sections 和 tool schemas 的组装。
6. 读 `packages/llm/llm`、`llm-deepseek`、`token-meter`，理解流式协议、适配器边界和压力估算。
7. 重点读 `packages/compaction`：先 service seam，再 basic backend，再 tool-result-pruner，最后追踪 overflow recovery。
8. 读 `packages/host`、`apps/web`，理解持久 Session 如何投影到 API 和 UI。
9. 用最小实验验证压力触发、裁剪、摘要失败、恢复和并发稳定性。

## 每个模块固定回答的问题

1. 输入来自哪里，输出交给谁？
2. 持有状态的对象是谁，状态何时改变？
3. 正常、错误、取消和卸载路径分别是什么？
4. 哪些数据必须持久化，哪些只是 live runtime state？
5. 与其他模块的同步/异步边界在哪里？
6. 哪个源码符号或测试能够证明结论？
