# DeepSeek Harness 项目档案

## 项目定位

DeepSeek Harness 是 DeepSeek AI 开源的 Agent Harness，核心特征是：

- 基于 Cordis 组织插件、服务、事件和可逆副作用。
- 模型适配器、工具注册、Session Log、Agent Loop 都不是特权内核，而是可替换插件。
- 通过 profile、bundle 和 `cordis.patch.yml` 叠加出实际运行配置。
- 当前处于 developer preview，行为和 API 仍可能发生破坏性变化。

## 学习边界

第一阶段关注通用 Harness 设计，不立即深入 Web UI 的全部渲染细节、native launcher、website 和第三方 vendor 实现。重点回答：

1. Cordis 插件树如何被装配？
2. 一次 Agent turn 如何驱动多个 step？
3. Session Log 如何成为模型上下文的来源？
4. System Prompt、Tools、runtime context 和消息历史如何合并？
5. 上下文压力如何测量，Compaction 如何保持一致性并收敛？
